# Changelog

## 1.1.2 (pre-release)

- Unit tests for classes and functions, for the whole app, chosen classes or the open file.
- Choose which screens to test from a list.
- Clear results: each screen shows why it failed, and the final message says how many tests work.
- Live progress, and a first-run guide.
- Open any test from the Testing panel, and add a failing test to your project if you want it.
- Better tests for GetX screens using `GetWidget`, and for screens whose controllers must be imported.
- Fix a false "does not compile" when Windows kept a temporary folder locked.

## 1.1.1 (pre-release)

- Fix Check Setup, which failed in PowerShell terminals. It now runs in the output panel.
