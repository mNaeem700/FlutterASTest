# Choose your AI

| Provider | Your code | You need |
|---|---|---|
| **local** | Stays on your machine | [Ollama](https://ollama.com) and a model; set its name in the `flutterastest.model` setting |
| **gemini** | Sent to Google | A Gemini API key |
| **openai** | Sent to that service | An API key for an OpenAI-compatible service |

Click **FlutterASTest** in the status bar to switch at any time. Keys stay in VS Code's secret storage.
