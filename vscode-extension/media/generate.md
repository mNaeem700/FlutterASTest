# Generate your first test

**How it works**

1. FlutterASTest reads your code and finds screens, widgets, navigation and state.
2. The AI writes tests from that information.
3. The tests run in your project. If one fails, the error goes back to the AI to repair it, up to 5 times.
4. Tests that pass are added to `test/flutterastest/`.

**Where to look**

- **Output panel:** what is happening now, and why something failed.
- **Testing panel, FlutterASTest section:** each screen's result. Click one to open its test. A failed test can be kept with **Add Test to Project**.

Your test suite stays green, because failing tests are only added if you choose to.
