# Changelog

## 1.0.0

- Generate Flutter widget tests from an AST-based Program Knowledge Graph.
- Local model by default; Gemini and OpenAI-compatible services with your own key, after asking.
- Run tests in the target project with coverage, reflection and mutation testing.
- Commands: `init`, `doctor`, `generate`, `config`, `batch`, `compare`, `accuracy`.
- Experiment groups, ablations, resumable batches and statistical comparison.
- VS Code extension.
